## Instalación

Para una correcta instalación debes de clonar el repositorio

```zsh
git clone http://github.com/jantonio05/solaris-web.git
cd solaris-web
```

## Configuración

Una vez realiza la instalación correctamente deberemos de instalar las dependencias del proyecto, esto lo conseguimos con el siguiente comando; 

```zsh
npm install
```

## Tecnologías

- TypeScript -5.9.2
- Angular - 20.3.4
- DaisyUI - 5.5.19
